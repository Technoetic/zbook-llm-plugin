# 이전 VGM 32GB 문서 — 읽기 전용 호환 안내

**현재 정책은 GPU 메모리 16GB 유지다.** 이 파일은 과거 링크를 위한 호환 안내이며, 32GB 변경 절차는 폐기했다.

현재 절차는 [GPU 메모리 16GB 유지 확인](vgm-16gb.md)을 따른다. `/vgm-check`를 실행하면 BIOS 설정값·설치 RAM·Windows 인식 총 RAM을 조회한다. `/vgm-32gb`도 같은 읽기 전용 검사를 실행하는 별칭이다. 어느 명령도 BIOS를 수정하거나 재부팅하지 않는다.

기존 35B-A3B 모델 측정은 32GB 설정에서 얻은 결과다. 16GB 설정에서는 이 모델을 측정하지 않았으므로, 16GB에서 실행 불가 또는 특정 속도라고 단정할 수 없다. 현재 4B 모델은 16GB 운영 기준을 유지한다.
