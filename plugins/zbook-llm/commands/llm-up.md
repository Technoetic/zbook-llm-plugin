로컬 AI 서버를 켜라:

1. 실행: `powershell -NoProfile -NonInteractive -ExecutionPolicy Bypass -File "${CLAUDE_PLUGIN_ROOT}/scripts/llm-up.ps1"` — 모델 로딩 때문에 최대 2분 걸릴 수 있으니 **도구 타임아웃을 300000ms(5분)로 지정해** 실행하라(기본 120초 타임아웃은 스크립트 대기 상한과 정확히 겹쳐, 하네스가 먼저 끊으면 서버는 뒤에서 뜨는데 "실패"로 보인다).
2. 종료코드가 0이면 기존 서버·신규 서버 모두 같은 포트로 `/llm-check`를 실행하라. 그 검증도 통과한 뒤 모델명·정답·소요 시간을 보고하라. 준비 상태 검사만으로 실추론 성공을 보고하지 않는다.
3. 출력에 `[중단]`이 나오면 함께 찍힌 `[다음]` 행을 그대로 사용자에게 전달하라 — 설치 폴더(`<드라이브>:\LLM`)를 못 찾는 경우는 로컬 AI 설치 패키지(「2. 설치.bat」)가 선행이다.
4. 이미 포트를 점유한 서버가 준비되지 않았거나 인증에 실패하면 중단한다. 자동으로 종료하거나 중복 기동하지 않는다. GPU 메모리는 **16GB 유지**이며 BIOS 변경·재부팅으로 우회하지 않는다.
5. 정상 가동 중인 서버는 모델이 4B여도 그대로 유지한다. 새로 기동할 때는 `models\default.txt`의 유효한 GGUF 파일명 지정(기존 4B 포함)을 우선한다. 지정이 없거나 유효하지 않으면 설치된 `Qwen3.5-9B-Q8_0.gguf` → `Qwen3.5-4B-Q8_0.gguf` → 최소 크기 GGUF 순서로 선택하며, 자동 선택에서 `mmproj*.gguf`는 제외한다. 모델 다운로드·기본 지정 덮어쓰기·서버 재시작은 자동으로 하지 않는다.
6. 모델 변경 요청에는 `${CLAUDE_PLUGIN_ROOT}/docs/model-policy-16gb.md`의 파일 확인 후 지정 절차를 적용한다. 지정 변경은 다음 기동에 적용되며 현재 서버를 바꾸지 않는다. 서버 소유자가 해당 서버를 종료·재기동하도록 안내하고, 전체 `llama-server` 프로세스를 일괄 종료하지 않는다.
7. 정확도 우선의 한국어 구조화 추출에는 9B Q8, 응답 속도 우선에는 4B Q8을 권장한다. 근거는 합성 자료의 1슬롯 실험이며, 일반 기동의 4슬롯 × 8192 성능이나 업무 정답을 보증하지 않는다. 서버 기본 temperature 0.8은 유지되므로 추출 요청에는 temperature 0·thinking false·JSON 스키마를 명시한다.
