description: ZBook Ultra G1a 그래픽 메모리(VGM) 32GB 설정 — 큰 AI 모델(20GB급)용, BIOS 화면 진입 없이 명령으로
---

ZBook의 GPU 전용 메모리를 32GB로 올리는 절차를 안내·실행하라. **절차 원문은 `${CLAUDE_PLUGIN_ROOT}/docs/vgm-32gb.md`를 Read로 먼저 읽고 그대로 따르라** — 아래는 진행 규칙이다.

1. **1단계(읽기 전용 확인)를 먼저 실행**하고 결과(기종·현재 설정·읽기전용·암호)를 사용자에게 보여라. 이미 `32 GB`면 여기서 종료(재부팅 여부만 확인).
2. **적용(2단계)은 사용자 확인을 받은 뒤에만 실행하라** — BIOS 설정 변경이다. "큰 모델(20GB급)을 쓸 계획인가"를 확인하고, 아니라면 권하지 마라(기본 4GB 모델에는 이 설정이 불필요하다).
3. 🚫 **어떤 경우에도 48GB를 선택하지 마라** — Windows에 16GB만 남아 야간 작업이 죽는다. 값은 항상 `'32 GB'`(띄어쓰기·대문자 그대로).
4. 적용 명령은 **관리자 권한이 필요**하다 — `Return : 6`(접근 거부)이 나오면 재시도하지 말고, 문서의 방법 A 명령 블록을 사용자에게 복사해 주며 "시작 버튼 우클릭 → 터미널(관리자)"에서 직접 붙여넣도록 안내하라.
5. `Return`이 0이 아니면 문서의 Return 코드 표대로만 대응하라 — 표에 없는 숫자는 임의 재시도 금지, 숫자를 그대로 보고.
6. 성공 후: **재부팅해야 반영**됨을 알리고, 재부팅 후 `/vgm-32gb`를 다시 부르면 3단계 검증(BIOS 값·VRAM·가용 RAM)을 실행해 완료 판정을 보고하라. 가용 RAM이 ~16GB 줄어드는 것은 정상(GPU로 이동)이라고 미리 말해줘라.
7. `BIOS 암호 : 1`이거나 총 메모리가 64GB가 아니면 진행을 멈추고 문서의 해당 절 안내만 전달하라.
